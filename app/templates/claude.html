Connexion Claude

Brancher Claude Desktop ou Claude Code sur le serveur, puis remplacer les fichiers de contexte d'un projet.

1Jeton d'accès

La valeur de MCP_TOKEN (fichier .env du serveur). Elle est enregistrée dans ce navigateur uniquement, jamais sur le serveur, et sert à préremplir les configurations ci-dessous.

2Brancher Claude sur le serveur

Claude Desktop (Node.js requis) : fusionner dans ~/Library/Application Support/Claude/claude_desktop_config.json, puis quitter et relancer Claude Desktop.

{
  "mcpServers": {
    "mcp-memory": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ url }}",
               "--header", "Authorization:${CONTEXTE_AUTH}"],
      "env": { "CONTEXTE_AUTH": "Bearer COLLER_ICI_LE_MCP_TOKEN" }
    }
  }
}

Démarrage plus rapide : npm i -g mcp-remote, puis remplacer "command": "npx" par le chemin de mcp-remote (which mcp-remote) et retirer "-y", "mcp-remote", des arguments.

Claude Code — le plus simple : ouvrir Claude Code sur le poste et lui demander (il enregistre le serveur en vous demandant le jeton, pose les hooks et vérifie le tout) :

Installe MCP Memory sur ce poste en suivant {{ url_installation(request) }}

Claude Code — à la main (serveur seul, sans les hooks) :

claude mcp add --transport http --scope user mcp-memory {{ url }} \
  --header "Authorization: Bearer COLLER_ICI_LE_MCP_TOKEN"

claude.ai web et mobile ne peuvent pas joindre ce serveur : il n'est pas exposé sur Internet.
