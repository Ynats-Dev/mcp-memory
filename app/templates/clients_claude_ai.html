Connecteur claude.ai (option, exige une exposition Internet)

claude.ai joint le serveur depuis Internet et s'authentifie en OAuth : le serveur MCP embarque son propre serveur OAuth, protégé par OAUTH_PASSWORD.

  1. Serveur : renseigner MCP_PUBLIC_URL et OAUTH_PASSWORD dans le .env (openssl rand -base64 18), puis docker compose up -d --build.
  2. Reverse proxy HTTPS : ne rendre publics que le endpoint MCP et le parcours OAuth ; l'interface web reste réservée au réseau local. Vérifier depuis l'extérieur : {{ url_publique or 'https://mcp.example.com' }}/.well-known/oauth-authorization-server → JSON.
  3. claude.ai → Réglages → Connecteurs → Ajouter un connecteur personnalisé : nom MCP Memory, URL {{ url }} → Se connecter → mot de passe OAUTH_PASSWORD. Le connecteur est alors disponible sur le web, le mobile et Claude Desktop.

Sécurité : seules les adresses de retour de claude.ai / claude.com sont acceptées ; 5 mauvais mots de passe bloquent la page 15 min ; jetons d'une heure renouvelés, 90 jours sans usage au maximum. Révoquer tous les accès : docker compose exec mcp rm /data/.oauth/etat.json && docker compose restart mcp.

Les hooks n'existent pas sur claude.ai : seules les directives et les procédures s'y appliquent.
