À la main : activer les hooks (une fois par poste)

Un seul hook, posé une fois dans ~/.claude/settings.json : avant chaque action, Claude Code interroge ce serveur, qui applique les règles de Claude › Hooks. Ensuite, tout se règle là.

  1. Nom du serveur. Dans un terminal : claude mcp list. Le nom est ce qui précède les deux-points (mcp-memory: https://…/mcp (HTTP) - ✔ Connected). Le reporter ici :
  2. Portée. claude mcp get mcp-memory doit afficher Scope: User config (serveur disponible dans tous les projets). Sinon, le réenregistrer avec --scope user (commande ci-dessus) : ailleurs, le hook ne trouverait pas le serveur et laisserait tout passer.
  3. Copier le bloc et le fusionner dans ~/.claude/settings.json, à côté des hooks existants (sans les remplacer). Vous pouvez aussi demander à Claude Code : « ajoute ce hook à mes réglages globaux ». 
    {{ config }}
  4. Vérifier. Dans Claude Code, /hooks doit lister le hook mcp_tool. Avec la règle « Me demander avant chaque git push » active, demander à Claude d'exécuter echo git push (sans effet) : une demande de confirmation doit apparaître.

Le bloc est fixe ("matcher": "*" : le serveur est consulté avant chaque action) : une règle ajoutée ici s'applique tout de suite, sans rien recopier. onFailure: continue : si le serveur est injoignable, l'action suit le circuit normal des permissions (mettre block pour tout bloquer dans ce cas). Les hooks n'existent que dans Claude Code : pour claude.ai et Claude Desktop, utilisez les directives.
