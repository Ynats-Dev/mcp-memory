Configuration

Claude Desktop ne lance que des serveurs locaux : le pont mcp-remote (Node.js requis) relaie vers ce serveur. Fusionner dans ~/Library/Application Support/Claude/claude_desktop_config.json, puis quitter et relancer Claude Desktop.

{
  "mcpServers": {
    "mcp-memory": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ url }}",
               "--header", "Authorization:${CONTEXTE_AUTH}"],
      "env": { "CONTEXTE_AUTH": "Bearer COLLER_ICI_LE_MCP_TOKEN" }
    }
  }
}

Démarrage plus rapide : npm i -g mcp-remote, puis remplacer "command": "npx" par le chemin de mcp-remote (which mcp-remote) et retirer "-y", "mcp-remote", des arguments.

Les hooks n'existent pas dans Claude Desktop : seules les directives et les procédures s'y appliquent.
