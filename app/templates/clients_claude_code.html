Le plus simple : demander à Claude Code

Ouvrir Claude Code sur le poste et lui demander :

Installe MCP Memory sur ce poste en suivant {{ url_installation(request) }}

Il enregistre le serveur (en vous demandant le jeton), pose le hook des règles et deux filets locaux (avertissement si le serveur est injoignable, règles Git appliquées même serveur éteint), règle l'attribution et la confirmation des git push, puis vérifie le tout.

À la main : enregistrer le serveur

claude mcp add --transport http --scope user mcp-memory {{ url }} \
  --header "Authorization: Bearer COLLER_ICI_LE_MCP_TOKEN"

Vérifier : claude mcp list (le serveur doit être « Connected ») et claude mcp get mcp-memory (Scope: User config).
